# Contributing

Keep changes scoped and include regression tests for capture, deduplication or data-integrity changes. Run python -m unittest discover -s tests -v before submitting.

Use synthetic fixtures only. Never submit real conversations, credentials, private project paths or vault history. Document the platform and assistant/CLI versions used. Do not describe an untested provider or desktop client as supported automatically; distinguish a tested hook, a generated integration, and a manual JSONL bridge.
